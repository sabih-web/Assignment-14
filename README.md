# Construction Website

A responsive website for a construction company. It presents the company's services, latest projects, client feedback and contact details in a clean, professional layout.

**Live Demo:** https://sabih-web.github.io/Construction-Site/

## About the Project

I built this project to practise designing a complete business website with multiple sections, from the homepage banner to the footer. The focus was on layout, clear structure and a professional look that works on all screen sizes.

## What's Inside

- Top bar with working hours and contact number
- Navigation bar with Home, About, Services, Projects, Blog and Contact
- Hero section with the headline "Build Your Dream"
- Services: Building Drawings, Painting Constructions and Repairing Constructions
- Features section: Basic Repairs, Repair Services and Preventive Maintenance
- Latest Projects gallery
- Statistics section (projects completed, happy clients, tasks completed, professionals)
- "Why We Are The Best" section
- Client feedback section
- Latest blog posts
- Contact message section and footer with newsletter

## Built With

- HTML
- CSS

## How to Run

1. Download or clone this repository
2. Open `index.html` in your browser

```bash
git clone https://github.com/sabih-web/Construction-Site.git
```
